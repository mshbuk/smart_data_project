# Events Prototype Sources

The Events feature uses `src/data/events.json` as a local prototype dataset.

The initial records were provided by the project owner for the June 2026 design pass and include Hamburg event examples such as Methfesselfest, Isemarkt, Hamburger Sommerdom, MS Dockville, ParkSport Wassermannpark, Deutsches Galoppderby, and World Triathlon Hamburg.

During implementation, public Hamburg event/calendar sources were checked for a stable API option. The prototype keeps a local JSON dataset for demo reliability instead of depending on a live feed. Event records include their source or map URL where one was supplied.

This dataset is presentation/demo content, not a guaranteed live event feed. Replace it with a verified API or regularly maintained source before treating event availability as factual.
